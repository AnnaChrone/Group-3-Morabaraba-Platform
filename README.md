# Group-3-Morabaraba-Platform
**ELEN3020A Group 3 2026**

This project is a Unity-based multiplayer Morabaraba board platform, using Unity 6.3 LTS (6000.3.9f1).  
Please ensure you are using the correct version of the Unity Editor.

This README provides a simple guide to help you understand the project structure and where key files can be found.

---

## Project Structure

All gameplay, UI, and networking scripts can be found in:

Assets/Scripts/


All test cases and testing-related scripts can be found in:

Assets/Tests/EditMode


**PLEASE NOTE: Should you wish to run the test cases, please comment out the demarked section of code within `BasicFunctions.cs` (found in `Assets/Scripts/`).**

A pre-built version of the game is included in the project for convenience:


ELEN3020A_Group3_Application_Build.zip


This build can be used to run the game without opening Unity if needed.

If you wish to run the Editor version of the game, please navigate to the scene "User Input" found in `Assets/Scenes` and run the game from that scene.
**HOWEVER**, it is strongly recommended that you run the game using the provided build so as to properly experience the game.

---

## Notes

- Ensure all required Unity packages are installed before running the project.  
- Multiplayer features require an active internet connection.
